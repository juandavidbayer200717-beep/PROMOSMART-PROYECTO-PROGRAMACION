# PromoSmart: simulador de promociones para comercio electrónico

Proyecto final de **ADMI 1301 – Introducción a la Programación** (Opción A: aplicación sencilla en Python).

## ¿Qué hace?
PromoSmart ayuda a una tienda en línea pequeña a decidir **qué promoción lanzar** antes de lanzarla. Con el precio, el costo, el inventario y las ventas esperadas, compara varios escenarios (sin promoción vs. con promociones) y muestra cuál deja **más ganancia**. Usa tres reglas:

1. Descuento según el tipo de cliente (Nuevo, Frecuente, VIP).
2. Descuento por volumen de compra.
3. Restricción de inventario (no se vende más de lo que hay en bodega).

## Cómo ejecutarlo
1. Abra `PromoSmart_Proyecto_Final.ipynb` en Google Colab, Jupyter o VS Code.
2. Ejecute todas las celdas en orden (*Run All*).
3. Para escribir sus propios datos, cambie `USAR_INPUT = False` por `USAR_INPUT = True` en el Paso 1.

Librerías necesarias: `pandas` y `matplotlib`. No se necesita ninguna base de datos externa: los datos de ejemplo están dentro del notebook.
